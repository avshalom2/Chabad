# Holiday guide work

For Hebrew printable holiday guides/PDFs, use the `hebrew-holiday-guides` skill. The project copy is [skills/hebrew-holiday-guides/SKILL.md](skills/hebrew-holiday-guides/SKILL.md); the personal installation has the same name.

The user's approved visual reference is the supplied `succot_guide_unified.pdf`, preserved inside the skill. Keep its designed cards, prayer panels and conditional additions. The older plain six-page Sukkot generator is not the approved design. User-supplied final download PDFs must not be regenerated unless the user asks for replacement.
